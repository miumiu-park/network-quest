# ランク評価

Stage Clear時のランクは、実行したcommand数、誤答数、hint使用数から決定します。
上位ランクから順に3項目すべての上限を満たすか評価し、最初に該当したランクを採用します。

| Rank | command数      | 誤答数        | hint使用数 |
| ---- | -------------- | ------------- | ---------- |
| S    | 4以下          | 0             | 0          |
| A    | 6以下          | 1以下         | 1以下      |
| B    | 10以下         | 2以下         | 2以下      |
| C    | 11以上、または | 3以上、または | 3以上      |

例えばcommand数が4でも誤答数が1ならA、command数が11なら他の項目が0でもCです。
各countは0以上の安全な整数だけを受け付けます。
